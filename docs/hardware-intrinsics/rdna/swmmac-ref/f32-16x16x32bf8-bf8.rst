``__builtin_amdgcn_swmmac_f32_16x16x32_bf8_bf8_w32``
""""""""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v8float __builtin_amdgcn_swmmac_f32_16x16x32_bf8_bf8_w32(
       v2int   srcA,
       v4int   srcB,
       v8float srcC,
       int     index);

Computes one step of a sparse :math:`16 \times 16` FP32 accumulation with BF8
(E5M2) inputs for both :math:`\pmb{A}` and :math:`\pmb{B}`.  Eight compressed
BF8 values per lane are packed into two 32-bit registers; sixteen dense BF8
values into four registers.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2int
     - Eight compressed BF8 elements of :math:`\pmb{A}` per lane, packed into
       two 32-bit registers (four 8-bit values per register).
   * - ``srcB``
     - v4int
     - Sixteen dense BF8 elements of :math:`\pmb{B}` per lane, packed into
       four 32-bit registers.
   * - ``srcC``
     - v8float
     - Accumulator input: eight FP32 elements per lane.
   * - ``index``
     - int
     - Sparsity index, see :ref:`rdna4-swmmac-common-parameters`.

**Returns** ``v8float`` -- updated accumulator
(:math:`\text{expand}(\text{srcA}, \text{index}) \times \text{srcB} + \text{srcC}`).
