``__builtin_amdgcn_wmma_i32_16x16x32_iu4_w32_gfx12``
""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v8int __builtin_amdgcn_wmma_i32_16x16x32_iu4_w32_gfx12(
       bool  a_neg,
       v2int srcA,
       bool  b_neg,
       v2int srcB,
       v8int srcC,
       bool  clamp);

Computes one step of a dense :math:`16 \times 16` INT32 accumulation with
4-bit integer inputs over a deeper K=32 strip.  Thirty-two INT4 elements of
:math:`\pmb{A}` are packed into two ``int`` registers per lane; likewise for
:math:`\pmb{B}`.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``a_neg``
     - bool
     - ``true`` for signed INT4, ``false`` for unsigned UINT4 in
       :math:`\pmb{A}`.  Compile-time constant, see
       :ref:`rdna4-dense-wmma-common-parameters`.
   * - ``srcA``
     - v2int
     - Thirty-two 4-bit elements of :math:`\pmb{A}` per lane, packed into two
       32-bit registers (sixteen 4-bit values per register).
   * - ``b_neg``
     - bool
     - ``true`` for signed INT4, ``false`` for unsigned UINT4 in
       :math:`\pmb{B}`.  Compile-time constant, see
       :ref:`rdna4-dense-wmma-common-parameters`.
   * - ``srcB``
     - v2int
     - Thirty-two 4-bit elements of :math:`\pmb{B}` per lane, packed into two
       32-bit registers.
   * - ``srcC``
     - v8int
     - Accumulator input: eight INT32 elements per lane.
   * - ``clamp``
     - bool
     - Clamp output to input type range on overflow.  Compile-time constant,
       see :ref:`rdna4-dense-wmma-common-parameters`.

**Returns** ``v8int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
