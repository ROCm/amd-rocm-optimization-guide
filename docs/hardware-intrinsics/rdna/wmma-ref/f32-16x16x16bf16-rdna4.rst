``__builtin_amdgcn_wmma_f32_16x16x16_bf16_w32_gfx12``
"""""""""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v8float __builtin_amdgcn_wmma_f32_16x16x16_bf16_w32_gfx12(
       v8short srcA,
       v8short srcB,
       v8float srcC);

Computes one step of a dense :math:`16 \times 16` FP32 accumulation with BF16
inputs.  BF16 values are passed as ``short`` (16-bit storage).  Otherwise
identical in structure to the FP16 variant.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v8short
     - Eight BF16 elements of :math:`\pmb{A}` per lane (BF16 stored as
       ``short``).
   * - ``srcB``
     - v8short
     - Eight BF16 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v8float
     - Accumulator input: eight FP32 elements per lane.

**Returns** ``v8float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
