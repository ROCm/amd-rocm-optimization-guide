``__builtin_amdgcn_wmma_f32_16x16x16_fp8_bf8_w32_gfx12``
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v8float __builtin_amdgcn_wmma_f32_16x16x16_fp8_bf8_w32_gfx12(
       v2int   srcA,
       v2int   srcB,
       v8float srcC);

Computes one step of a dense :math:`16 \times 16` FP32 accumulation with
mixed 8-bit floating-point inputs: FP8 (E4M3) for :math:`\pmb{A}` and BF8
(E5M2) for :math:`\pmb{B}`.  Eight elements per lane are packed into two
32-bit registers.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2int
     - Eight FP8 elements of :math:`\pmb{A}` per lane, packed into two
       32-bit registers (four 8-bit values per register).
   * - ``srcB``
     - v2int
     - Eight BF8 elements of :math:`\pmb{B}` per lane, packed into two
       32-bit registers.
   * - ``srcC``
     - v8float
     - Accumulator input: eight FP32 elements per lane.

**Returns** ``v8float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
