``__builtin_amdgcn_wmma_f32_16x16x16_f16_w32``
""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v8float __builtin_amdgcn_wmma_f32_16x16x16_f16_w32(
       v16half srcA,
       v16half srcB,
       v8float srcC);

Computes one step of a dense :math:`16 \times 16` FP32 accumulation with FP16
inputs.  Each lane supplies 16 FP16 values for both :math:`\pmb{A}` and
:math:`\pmb{B}`.  Due to matrix replication, the 16-element fragment is indexed
by ``lane_id % 16``, so lanes 0--15 and 16--31 carry identical copies.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v16half
     - Sixteen FP16 elements of :math:`\pmb{A}` per lane (one full row of the
       :math:`16 \times 16` A tile, replicated across both lane groups).
   * - ``srcB``
     - v16half
     - Sixteen FP16 elements of :math:`\pmb{B}` per lane (one full column of
       the :math:`16 \times 16` B tile, replicated across both lane groups).
   * - ``srcC``
     - v8float
     - Accumulator input: eight FP32 elements per lane.

**Returns** ``v8float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
