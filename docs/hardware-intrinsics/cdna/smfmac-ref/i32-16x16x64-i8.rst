``__builtin_amdgcn_smfmac_i32_16x16x64_i8``
"""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v4int __builtin_amdgcn_smfmac_i32_16x16x64_i8(
       v2int  srcA,
       v4int  srcB,
       v4int  srcC,
       int    idx,
       int    cbsz,
       int    abid);

Computes one step of a :math:`16 \times 16` sparse INT32 outer-product
accumulation.  Each instruction processes :math:`K=64` compressed INT8
elements of :math:`\pmb{A}` and :math:`K=64` dense INT8 elements of
:math:`\pmb{B}`, accumulating into a :math:`16 \times 16` INT32 tile held
across 4 accVGPRs per lane.  Each 32-bit register lane packs four INT8
elements.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2int
     - Compressed :math:`\pmb{A}` elements per lane (4:2 sparse, four INT8
       values packed per 32-bit lane).
   * - ``srcB``
     - v4int
     - Dense :math:`\pmb{B}` elements per lane (four INT8 values packed per
       32-bit lane).
   * - ``srcC``
     - v4int
     - Accumulator input: 4 INT32 elements per lane.
   * - ``idx``
     - int
     - Sparsity index encoding the positions of non-zero elements within
       each group of four along the K dimension, see
       :ref:`smfmac-common-parameters`.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`smfmac-common-parameters`.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier, see
       :ref:`smfmac-common-parameters`.

**Returns** ``v4int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
