``__builtin_amdgcn_smfmac_f32_32x32x16_bf16``
"""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v16float __builtin_amdgcn_smfmac_f32_32x32x16_bf16(
       v4short   srcA,
       v8short   srcB,
       v16float  srcC,
       int       idx,
       int       cbsz,
       int       abid);

Computes one step of a :math:`32 \times 32` sparse FP32 outer-product
accumulation.  Each instruction processes :math:`K=16` compressed BF16
elements of :math:`\pmb{A}` and :math:`K=16` dense BF16 elements of
:math:`\pmb{B}`, accumulating into a :math:`32 \times 32` FP32 tile held
across 16 accVGPRs per lane.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v4short
     - Compressed :math:`\pmb{A}` elements per lane (4:2 sparse, BF16
       stored as ``short``).
   * - ``srcB``
     - v8short
     - Dense :math:`\pmb{B}` elements per lane (BF16 stored as ``short``).
   * - ``srcC``
     - v16float
     - Accumulator input: 16 FP32 elements per lane.
   * - ``idx``
     - int
     - Sparsity index encoding the positions of non-zero elements within
       each group of four along the K dimension, see
       :ref:`smfmac-common-parameters`.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`smfmac-common-parameters`.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier, see
       :ref:`smfmac-common-parameters`.

**Returns** ``v16float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
