``__builtin_amdgcn_mfma_i32_32x32x32_i8``
""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v16int __builtin_amdgcn_mfma_i32_32x32x32_i8(
       v4int  srcA,
       v4int  srcB,
       v16int srcC,
       int    cbsz,
       int    abid,
       int    blgp);

Computes one step of a :math:`32 \times 32` INT8→INT32 matrix
multiply-accumulate. Each instruction processes :math:`K=32` INT8 column
elements of :math:`\pmb{A}`
and :math:`K=32` INT8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`32 \times 32` INT32 tile. Each lane holds 16 signed 8-bit integers packed
into a ``v4int`` (four 32-bit words) for each of :math:`\pmb{A}` and
:math:`\pmb{B}`.

This is a **single-block** variant. The result is a ``v16int`` (16 INT32
elements per lane) using accVGPRs 0--15 in the :math:`32 \times 32` layout.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v4int
     - Sixteen INT8 elements of :math:`\pmb{A}` per lane, packed as four
       32-bit words.
   * - ``srcB``
     - v4int
     - Sixteen INT8 elements of :math:`\pmb{B}` per lane, packed as four
       32-bit words.
   * - ``srcC``
     - v16int
     - Accumulator input: 16 INT32 elements per lane.
   * - ``cbsz``
     - int
     - Reserved. Must be ``0`` (single-block variant; broadcast modifier
       not supported).
   * - ``abid``
     - int
     - Reserved. Must be ``0`` (single-block variant; block ID modifier
       not supported).
   * - ``blgp``
     - int
     - Lane-group pattern modifier. See :ref:`cdna-mfma-common-parameters`.

**Returns** ``v16int`` -- updated accumulator.

.. note::

   This single-block variant does not support the ``cbsz`` and ``abid``
   broadcast modifiers; both must be ``0``.
