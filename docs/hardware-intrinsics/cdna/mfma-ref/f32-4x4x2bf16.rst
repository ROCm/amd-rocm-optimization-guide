``__builtin_amdgcn_mfma_f32_4x4x2bf16``
"""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v4float __builtin_amdgcn_mfma_f32_4x4x2bf16(
       v2bfloat srcA,
       v2bfloat srcB,
       v4float  srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`4 \times 4` FP32 outer-product accumulation. Each
instruction processes :math:`K=2` BF16 column elements of :math:`\pmb{A}` and
:math:`K=2` BF16 row elements of :math:`\pmb{B}`, accumulating into a
:math:`4 \times 4` FP32 tile held across 4 accVGPRs per lane. This intrinsic
operates on 16 input blocks.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2bfloat
     - Two elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v2bfloat
     - Two elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v4float
     - Accumulator input: 4 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..4
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..15
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna-mfma-common-parameters`.

**Returns** ``v4float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
