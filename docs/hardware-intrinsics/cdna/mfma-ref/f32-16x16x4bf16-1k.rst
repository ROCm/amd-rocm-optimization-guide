``__builtin_amdgcn_mfma_f32_16x16x4bf16_1k``
"""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v16float __builtin_amdgcn_mfma_f32_16x16x4bf16_1k(
       v4bfloat srcA,
       v4bfloat srcB,
       v16float srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`16 \times 16` FP32 outer-product accumulation.
Each instruction processes :math:`K=4` BF16 column elements of :math:`\pmb{A}`
and :math:`K=4` BF16 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` FP32 tile held across 16 accVGPRs per lane. This intrinsic
operates on four input blocks and uses IEEE round-to-nearest-even for partial
products.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v4bfloat
     - Four BF16 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v4bfloat
     - Four BF16 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v16float
     - Accumulator input: 16 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna2-mfma-common-parameters`.
       Legal range: 0..2
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna2-mfma-common-parameters`.
       Legal range: 0..3
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna2-mfma-common-parameters`.

**Returns** ``v16float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
