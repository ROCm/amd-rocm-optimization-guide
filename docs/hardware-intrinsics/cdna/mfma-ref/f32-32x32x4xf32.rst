``__builtin_amdgcn_mfma_f32_32x32x4_xf32``
""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v16float __builtin_amdgcn_mfma_f32_32x32x4_xf32(
       v2float  srcA,
       v2float  srcB,
       v16float srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`32 \times 32` FP32 outer-product accumulation.
Each instruction processes :math:`K=4` XF32 column elements of :math:`\pmb{A}`
and :math:`K=4` XF32 row elements of :math:`\pmb{B}`, accumulating into a
:math:`32 \times 32` FP32 tile held across 16 accVGPRs per lane. This intrinsic
operates on a single input block.

eXtended Float32 (XF32) accepts standard FP32 (IEEE binary32) inputs but
rounds each mantissa to 10 bits before multiplication, providing higher
throughput than full FP32 matrix multiplication. Each lane provides two values
packed into a ``v2float`` register.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2float
     - Two XF32 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v2float
     - Two XF32 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v16float
     - Accumulator input: 16 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.

   * - ``abid``
     - int

       see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - Must be ``0``.

**Returns** ``v16float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
