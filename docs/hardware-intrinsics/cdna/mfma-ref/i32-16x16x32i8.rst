``__builtin_amdgcn_mfma_i32_16x16x32_i8``
"""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v4int __builtin_amdgcn_mfma_i32_16x16x32_i8(
       long long srcA,
       long long srcB,
       v4int     srcC,
       int       cbsz,
       int       abid,
       int       blgp);

Computes one step of a :math:`16 \times 16` INT32 outer-product accumulation.
Each instruction processes :math:`K=32` INT8 column elements of :math:`\pmb{A}`
and :math:`K=32` INT8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` INT32 tile held across 4 accVGPRs per lane. This intrinsic
operates on a single input block.

Each lane provides eight signed 8-bit integer values packed into a ``long long``
register for both :math:`\pmb{A}` and :math:`\pmb{B}`.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - long long
     - Eight INT8 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - long long
     - Eight INT8 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v4int
     - Accumulator input: 4 INT32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - Must be ``0``.

**Returns** ``v4int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
