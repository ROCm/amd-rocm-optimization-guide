``__builtin_amdgcn_mfma_f32_16x16x32_f16``
""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this intrinsic.

.. code-block:: cpp

   v4float __builtin_amdgcn_mfma_f32_16x16x32_f16(
       v8half  srcA,
       v8half  srcB,
       v4float srcC,
       int     cbsz,
       int     abid,
       int     blgp);

Computes one step of a :math:`16 \times 16` FP16→FP32 matrix
multiply-accumulate. Each instruction processes :math:`K=32` FP16 column
elements of :math:`\pmb{A}`
and :math:`K=32` FP16 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` FP32 tile. Each lane holds eight FP16 values packed into
one ``v8half`` register for each of :math:`\pmb{A}` and :math:`\pmb{B}`.

This is a **single-block** variant. The result is a ``v4float`` (4 FP32 elements
per lane) using accVGPRs 0--3 in the :math:`16 \times 16` layout.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v8half
     - Eight FP16 elements of :math:`\pmb{A}` per lane, packed into a
       128-bit register.
   * - ``srcB``
     - v8half
     - Eight FP16 elements of :math:`\pmb{B}` per lane, packed into a
       128-bit register.
   * - ``srcC``
     - v4float
     - Accumulator input: 4 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Reserved. Must be ``0`` (single-block variant; broadcast modifier
       not supported).
   * - ``abid``
     - int
     - Reserved. Must be ``0`` (single-block variant; block ID modifier
       not supported).
   * - ``blgp``
     - int
     - Lane-group pattern modifier. See :ref:`cdna-mfma-common-parameters`.

**Returns** ``v4float`` -- updated accumulator.

.. note::

   This single-block variant does not support the ``cbsz`` and ``abid``
   broadcast modifiers; both must be ``0``.
