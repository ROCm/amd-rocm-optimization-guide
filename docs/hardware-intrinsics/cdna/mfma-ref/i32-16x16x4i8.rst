``__builtin_amdgcn_mfma_i32_16x16x4i8``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: cpp

   v16int __builtin_amdgcn_mfma_i32_16x16x4i8(
       int    srcA,
       int    srcB,
       v16int srcC,
       int    cbsz,
       int    abid,
       int    blgp);

Computes one step of a :math:`16 \times 16` INT32 outer-product accumulation. 
Each instruction processes :math:`K=4` INT8 column elements of :math:`\pmb{A}`
and :math:`K=4` INT8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` INT32 tile held across 16 accVGPRs per lane. This intrinsic
operates on four input blocks.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - int
     - Four elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - int
     - Four elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v16int
     - Accumulator input: 16 INT32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..2
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..3
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna-mfma-common-parameters`.

**Returns** ``v16int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
