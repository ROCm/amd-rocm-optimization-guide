``__builtin_amdgcn_mfma_f32_32x32x2bf16``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: cpp

   v32float __builtin_amdgcn_mfma_f32_32x32x2bf16(
       v2bfloat srcA,
       v2bfloat srcB,
       v32float srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`32 \times 32` FP32 outer-product accumulation. 
Each instruction processes :math:`K=2` BF16 column elements of :math:`\pmb{A}`
and :math:`K=2` BF16 row elements of :math:`\pmb{B}`, accumulating into a
:math:`32 \times 32` FP32 tile held across 32 accVGPRs per lane. This intrinsic
operates on two input blocks.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2bfloat
     - Two elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v2bfloat
     - Two elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v32float
     - Accumulator input: 32 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..1
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..1
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna-mfma-common-parameters`.

**Returns** ``v32float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
