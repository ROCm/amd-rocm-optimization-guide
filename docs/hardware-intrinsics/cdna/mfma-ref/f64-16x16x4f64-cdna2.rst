``__builtin_amdgcn_mfma_f64_16x16x4f64``
""""""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v4double __builtin_amdgcn_mfma_f64_16x16x4f64(
       double   srcA,
       double   srcB,
       v4double srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`16 \times 16` FP64 outer-product accumulation.
Each instruction processes :math:`K=4` FP64 column elements of :math:`\pmb{A}`
and :math:`K=4` FP64 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` FP64 tile held across 4 accVGPRs per lane (8 physical
accVGPRs, since each FP64 value occupies two 32-bit registers). This intrinsic
operates on a single input block.  Partial products use IEEE
round-to-nearest-even rather than round-to-zero.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - double
     - One FP64 element of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - double
     - One FP64 element of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v4double
     - Accumulator input: 4 FP64 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna2-mfma-common-parameters`.
       Must be ``0``.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna2-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - Reserved. Must be ``0``.

**Returns** ``v4double`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).

.. note::

   Unlike FP32, BF16, and INT8 MFMA instructions, FP64 MFMA instructions
   cannot co-execute with VALU instructions. To hide execution latency,
   schedule non-VALU instructions (loads, stores, or branches) around
   FP64 MFMA operations.
