``__builtin_amdgcn_mfma_i32_4x4x4i8``
"""""""""""""""""""""""""""""""""""""""

.. code-block:: cpp

   v4int __builtin_amdgcn_mfma_i32_4x4x4i8(
       int   srcA,
       int   srcB,
       v4int srcC,
       int   cbsz,
       int   abid,
       int   blgp);

Computes one step of a :math:`4 \times 4` INT32 outer-product accumulation. Each
instruction processes :math:`K=4` INT8 column elements of :math:`\pmb{A}` and
:math:`K=4` INT8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`4 \times 4` INT32 tile held across 4 accVGPRs per lane. This intrinsic
operates on 16 input blocks.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - int
     - Four elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - int
     - Four elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v4int
     - Accumulator input: 4 INT32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..4
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Legal range: 0..15
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna-mfma-common-parameters`.

**Returns** ``v4int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
