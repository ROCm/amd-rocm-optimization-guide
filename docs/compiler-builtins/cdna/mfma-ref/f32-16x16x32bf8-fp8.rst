``__builtin_amdgcn_mfma_f32_16x16x32_bf8_fp8``
""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v4float __builtin_amdgcn_mfma_f32_16x16x32_bf8_fp8(
       long long srcA,
       long long srcB,
       v4float   srcC,
       int       cbsz,
       int       abid,
       int       blgp);

Computes one step of a :math:`16 \times 16` FP32 outer-product accumulation.
Each instruction processes :math:`K=32` BF8 column elements of :math:`\pmb{A}`
and :math:`K=32` FP8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`16 \times 16` FP32 tile held across 4 accVGPRs per lane. This builtin
operates on a single input block.

:math:`\pmb{A}` uses the BF8 (E5M2) format and :math:`\pmb{B}` uses the FP8
(E4M3) format; eight 8-bit values are packed into a ``long long`` register per
lane for each operand.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - long long
     - Eight BF8 (E5M2) elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - long long
     - Eight FP8 (E4M3) elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v4float
     - Accumulator input: 4 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - Must be ``0``.

**Returns** ``v4float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
