``__builtin_amdgcn_mfma_i32_32x32x16_i8``
"""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v16int __builtin_amdgcn_mfma_i32_32x32x16_i8(
       long long srcA,
       long long srcB,
       v16int    srcC,
       int       cbsz,
       int       abid,
       int       blgp);

Computes one step of a :math:`32 \times 32` INT32 outer-product accumulation.
Each instruction processes :math:`K=16` INT8 column elements of :math:`\pmb{A}`
and :math:`K=16` INT8 row elements of :math:`\pmb{B}`, accumulating into a
:math:`32 \times 32` INT32 tile held across 16 accVGPRs per lane. This builtin
operates on a single input block.

Each lane provides eight signed 8-bit integer values packed into a ``long long``
register for both :math:`\pmb{A}` and :math:`\pmb{B}`.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - long long
     - Eight INT8 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - long long
     - Eight INT8 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v16int
     - Accumulator input: 16 INT32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - Must be ``0``.

**Returns** ``v16int`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
