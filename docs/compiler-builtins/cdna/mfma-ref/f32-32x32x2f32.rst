``__builtin_amdgcn_mfma_f32_32x32x2f32``
""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v16float __builtin_amdgcn_mfma_f32_32x32x2f32(
       float    srcA,
       float    srcB,
       v16float srcC,
       int      cbsz,
       int      abid,
       int      blgp);

Computes one step of a :math:`32 \times 32` FP32 outer-product accumulation. 
Each instruction processes :math:`K=2` FP32 column elements of :math:`\pmb{A}`
and :math:`K=2` FP32 row elements of :math:`\pmb{B}`, accumulating into a
:math:`32 \times 32` FP32 tile held across 16 accVGPRs per lane. This builtin
operates on a single input block.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - float
     - One element of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - float
     - One element of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v16float
     - Accumulator input: 16 FP32 elements per lane.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier,
       see :ref:`cdna-mfma-common-parameters`.
       Must be ``0``.
   * - ``blgp``
     - int
     - :math:`\pmb{B}`-matrix Lane Group Pattern modifier, see
       :ref:`cdna-mfma-common-parameters`.

**Returns** ``v16float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
