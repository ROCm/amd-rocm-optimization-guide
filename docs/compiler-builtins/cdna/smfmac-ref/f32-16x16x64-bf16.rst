``__builtin_amdgcn_smfmac_f32_16x16x64_bf16``
"""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v4float __builtin_amdgcn_smfmac_f32_16x16x64_bf16(
       v8bf16  srcA,
       v16bf16 srcB,
       v4float srcC,
       int     idx,
       int     cbsz,
       int     abid);

Computes one step of a :math:`16 \times 16` sparse FP32 outer-product
accumulation.  Each instruction processes :math:`K=64` compressed BF16
elements of :math:`\pmb{A}` and :math:`K=64` dense BF16 elements of
:math:`\pmb{B}`, accumulating into a :math:`16 \times 16` FP32 tile held
across 4 accVGPRs per lane.  This variant is available on ``gfx950`` only.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v8bf16
     - Compressed :math:`\pmb{A}` elements per lane (4:2 sparse, BF16
       stored as ``__bf16``).
   * - ``srcB``
     - v16bf16
     - Dense :math:`\pmb{B}` elements per lane (BF16 stored as ``__bf16``).
   * - ``srcC``
     - v4float
     - Accumulator input: 4 FP32 elements per lane.
   * - ``idx``
     - int
     - Sparsity index encoding the positions of non-zero elements within
       each group of four along the K dimension, see
       :ref:`smfmac-common-parameters`.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`smfmac-common-parameters`.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier, see
       :ref:`smfmac-common-parameters`.

**Returns** ``v4float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
