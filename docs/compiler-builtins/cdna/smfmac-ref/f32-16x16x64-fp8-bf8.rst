``__builtin_amdgcn_smfmac_f32_16x16x64_fp8_bf8``
""""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v4float __builtin_amdgcn_smfmac_f32_16x16x64_fp8_bf8(
       v2int    srcA,
       v4int    srcB,
       v4float  srcC,
       int      idx,
       int      cbsz,
       int      abid);

Computes one step of a :math:`16 \times 16` sparse FP32 outer-product
accumulation.  Each instruction processes :math:`K=64` compressed FP8 (E4M3)
elements of :math:`\pmb{A}` and :math:`K=64` dense BF8 (E5M2) elements of
:math:`\pmb{B}`, accumulating into a :math:`16 \times 16` FP32 tile held
across 4 accVGPRs per lane.  Each 32-bit register lane packs four 8-bit
elements.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v2int
     - Compressed :math:`\pmb{A}` elements per lane (4:2 sparse, four
       FP8 (E4M3) values packed per 32-bit lane).
   * - ``srcB``
     - v4int
     - Dense :math:`\pmb{B}` elements per lane (four BF8 (E5M2) values
       packed per 32-bit lane).
   * - ``srcC``
     - v4float
     - Accumulator input: 4 FP32 elements per lane.
   * - ``idx``
     - int
     - Sparsity index encoding the positions of non-zero elements within
       each group of four along the K dimension, see
       :ref:`smfmac-common-parameters`.
   * - ``cbsz``
     - int
     - Control Broadcast Size modifier, see :ref:`smfmac-common-parameters`.
   * - ``abid``
     - int
     - :math:`\pmb{A}`-matrix Broadcast Identifier, see
       :ref:`smfmac-common-parameters`.

**Returns** ``v4float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
