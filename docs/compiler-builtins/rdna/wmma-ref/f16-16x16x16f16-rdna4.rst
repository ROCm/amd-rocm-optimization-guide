Signature and parameters for this builtin.

.. code-block:: cpp

   v8half __builtin_amdgcn_wmma_f16_16x16x16_f16_w32_gfx12(
       v8half srcA,
       v8half srcB,
       v8half srcC);

Computes one step of a dense :math:`16 \times 16` FP16 accumulation.  Both
inputs and the accumulator are FP16.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v8half
     - Eight FP16 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v8half
     - Eight FP16 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v8half
     - Accumulator input: eight FP16 elements per lane.

**Returns** ``v8half`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
