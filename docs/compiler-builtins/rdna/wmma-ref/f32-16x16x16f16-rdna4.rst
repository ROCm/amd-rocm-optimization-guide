``__builtin_amdgcn_wmma_f32_16x16x16_f16_w32_gfx12``
""""""""""""""""""""""""""""""""""""""""""""""""""""

Signature and parameters for this builtin.

.. code-block:: cpp

   v8float __builtin_amdgcn_wmma_f32_16x16x16_f16_w32_gfx12(
       v8half  srcA,
       v8half  srcB,
       v8float srcC);

Computes one step of a dense :math:`16 \times 16` FP32 accumulation with FP16
inputs.  Each lane supplies 8 FP16 values for both :math:`\pmb{A}` and
:math:`\pmb{B}`.  The 32 lanes form two groups of 16; each group covers 8 of
the 16 K-positions.

.. list-table::
   :header-rows: 1
   :widths: auto

   * - Parameter
     - Type
     - Description
   * - ``srcA``
     - v8half
     - Eight FP16 elements of :math:`\pmb{A}` per lane.
   * - ``srcB``
     - v8half
     - Eight FP16 elements of :math:`\pmb{B}` per lane.
   * - ``srcC``
     - v8float
     - Accumulator input: eight FP32 elements per lane.

**Returns** ``v8float`` -- updated accumulator
(:math:`\text{srcA} \times \text{srcB} + \text{srcC}`).
